Un ejemplo claro:

1) Pregunta del usuario

2) Regex que activa el enrutado

En patterns existe este patrón para padre:
(r"(pare|padre|father)\b", "handle_father")

Después, dentro de handle_father, se usan prefijos para extraer el nombre:

Python
prefixes = [
    r"(?:pare|padre|father)\s+(?:de|d\'|of)\s+",
    r"(?:qui|quien|who)\s+.*(?:pare|padre|father)",
]

Con eso, para la pregunta “¿Quién es el padre de Juan Godes?”, el router intenta aislar “Juan Godes” como nombre objetivo.

3) Resolución previa del nombre

Antes de consultar el padre, el router busca a la persona con:

Python
matches = find_person_by_name(self.conn, name)

Y find_person_by_name() llama a search_people(), que hace esta consulta SQL:

SQL
SELECT id, name, given_name, surname, nickname, birth_year, death_year, photo_file, is_alive
FROM people
WHERE name LIKE ? COLLATE NOCASE
ORDER BY name
LIMIT ?

Con parámetros del tipo:

SQL
name LIKE "%Juan%Godes%"
limit = 5

porque el código normaliza espacios a % para permitir coincidencias flexibles.

4) Query SQL final contra SQLite

Una vez encontrada la persona, handle_father() hace:

Python
full = get_person(self.conn, person["id"])
father = get_person(self.conn, full["father_id"])

Y get_person() ejecuta:

SQL
SELECT * FROM people WHERE id = ?

Primero con el id de Juan Godes, y luego con el father_id recuperado de esa fila.

Cómo se lee el flujo real

En casi todos los casos el pipeline es este:

  1. route() recorre self.patterns y encuentra el primer regex que hace match.

  2. El handler intenta extraer la entidad con _extract_name() o _find_person_in_question().

6. Reglas de desambiguación que ya puedes fijar

El corpus las pide a gritos. Yo dejaría estas:

  1. Nombre exacto + año vence a todo.

  2. Nombre exacto + lugar vence a nombre sin contexto.

  3. Nombre parcial nunca devuelve una sola persona si hay varias coincidencias fuertes.

  4. Apellido solo se trata como consulta grupal, no como persona.

  5. Topónimos deben pasar por normalización antes de filtrar.

  6. Si hay empate real, el sistema lista candidatos, no inventa uno.

Esto encaja muy bien con la sección de preguntas ambiguas.
